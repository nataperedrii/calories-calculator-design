Ripe design system

Tokens and components for a photo-first calorie calculator. Every value comes from tokens.json (W3C format). tokens.css is generated from it, and components.css uses nothing but those variables. Screens are 390×844, light theme, WCAG AA. Verified with npm run check.

FoundationsColour

Components24 components, every state

States are shown with .is-pressed, .is-disabled, .is-focus and .is-error. In the app they come from :active, :disabled, :focus-visible and aria-invalid. All numbers are real USDA values. Every state keeps its visuals inside its parent, and text is never clipped.

01

Buttons

.btn--primary · --secondary · --ghost · --destructive · .icon-btn
  • One primary button per screen. It does the main job, like "Add to Lunch".
  • Label = verb + object. Add the kcal total when it helps the user decide.
  • Heights: 52 (L) and 44 (M; 48 on Android). Icon buttons are 44×44 (48×48 on Android) around a 24 glyph.
  • Don't use destructive styling for "over goal". It's only for deleting data, and it always opens a confirm sheet that lists what will be deleted and offers 30 days to undo.
02

Text field

.field · .field__control · .field__suffix · .field__help
  • Always a visible label. The placeholder is only an example.
  • Units live in the suffix (g, ml, kcal) and are set in Azeret Mono.
  • Errors say how to fix it, not just that something is wrong.
  • The border is an inset ring, so focus and error never change the size.
03

Search bar

.search
  • Recent foods show first, before any typing (research insight 4).
  • Barcode lives inside the bar, so there's one place to find food.
  • No results → offer help: check spelling, add a custom food, or scan.
04

Chips

.chip · .is-selected · .chip--fresh · .chip--locked
  • For filters and quick choices, such as recipe filters and "Is it olive oil or teriyaki?".
  • Selected = apricot fill + persimmon ring + check icon, so it's not colour alone.
  • Visual height is 36; the hit region is extended to 44 (48 on Android).
  • Allergy filters are locked: a lock icon and the word "Allergy", never colour alone. They can only be changed in Profile, so a tap can't show unsafe recipes.
05

Segmented control

.segmented · .segmented__opt
  • Switches the unit for a portion: grams, millilitres or portions.
  • Disable options that don't apply (for example ml for rice) rather than hiding them.
  • Focus = 2 px surface gap + 2 px rye ring outside the segment. It fits exactly into the 4 px track padding and the 8 px gap between segments.
06

Weight stepper

.stepper · .stepper__btn · .stepper__value
  • Tap ± for 10 g steps; tap the value to type an exact weight.
  • The kcal next to it updates live. This is how users fix photo estimates.
  • The border is an inset ring, so each ± button is a full 44×44 hit region.
07

Product list item

.list · .product · .product--detected · .is-check · .product__thumb--icon
  • One canonical entry per food. The source (USDA) is named on the detail screen, not in the list.
  • kcal and P · F · C are per 100 g, rounded to whole grams in lists. Decimals appear on the detail screen.
  • Identical geometry in every state: rows are inset 4 px in the list, have a 16 px radius, and draw outlines as a 2 px inset ring. Dividers hide next to a highlighted row.
  • Search rows (.product--chips): the product photo (the same .product__thumb as the Meals rows: size-thumb, radius-sm, cover; alt="" beside the name) with the name to its right, top-aligned, wrapping, never clipped. Under the photo, from the card-inset line, the P / F / C chips (.product__macros), space-2 below the photo. kcal per 100 g and the Add button (44, "Add <food>", focus ring with a gap) sit on the right edge, centred on the whole row.
  • Settings rows (.product--nav, Profile): an icon tile, the name and its value, and a plain chevron button (44, named "Edit allergies"). Its glyph sits on the inset line, like every plain icon button at a row end.
  • Meal rows: a logged meal shows its dish photo. An empty meal shows a passive meal-type icon in the same 48 slot (not a button: no hit area, no states) and exactly one Add button on the right, so rows never shift.
  • Detected item (photo result): the photo marker number, the name, a confidence label, a weight stepper and kcal. Check portion tints the row so the user confirms the weight. A thumbnail is a real photo (<img class="product__thumb">) or, when there's none, an icon tile.
08

Recipe card

.recipe-card · .recipe-card--compact · .recipe-card__fit
  • Leads with "fits your …" when the recipe fits the kcal left (research insight 3).
  • kcal per portion is the biggest number; macros sit in the meta row.
  • No fixed height, no clipping. Long titles wrap and the card grows, including at 200% text size.
  • Macros are chips, the same macro-tile component as the detail screen: letter + value in the macro colours, no dot separators. Gap letter → value = --space-inline-icon (4, the clock → time gap); gap between chips = --space-chip-gap (8).
  • "View recipe" is a real button (secondary, 12.8:1, 44 tall) named "View recipe: <dish>"; Enter and Space open the dish.
  • Compact card for ranked lists: an image column --size-recipe-thumb (80) wide that runs from the top to the bottom padding of the card and grows with the text (grid align-items: stretch, object-fit cover, its own radius on all four corners; the card never clips) and one left-aligned text column (min-width: 0): title → time → reason → P / F / C → "Fits: 532 of 879 kcal" → kcal. Every row is --space-2 (8) apart; padding = --space-card-inset, image → text = --space-3. An optional "Best fit" badge sits above the title. The fit line is text, not colour alone.
  • Clickable image (.recipe-card__img--link): on the full card the image is a pointer shortcut to the recipe (pointer cursor, pressed overlay). It is aria-hidden and not focusable, so "View recipe" stays the single keyboard and screen-reader path.
09

Nutrition summary

.nutri · .nutri__ring · .macros · .macro--p/f/c
  • Leads with kcal left, not kcal eaten. It answers "can I have dinner?".
  • Macros are always ordered P → F → C, each with a letter, a value, a bar and the goal.
  • Over goal: the ring and number turn Turmeric, and the copy stays neutral.
  • Never red, never "warning", never an exclamation mark for going over.
10

Nutrition facts table

.facts
  • Two columns: per 100 g and per portion, so users can compare foods and see their meal.
  • Energy row first, between heavy rules; sub-rows ("of which…") are indented.
  • The source is always shown under the title.
11

Top app bar

.app-bar · .app-bar--large · .is-scrolled
  • Sits below the 47 pt status bar. 56 pt on iOS, 64 dp on Android (Material 3).
  • Icons are 24 inside 44 pt (48 dp) buttons.
  • Titles wrap instead of truncating. When content scrolls under the bar, it switches to the surface colour with a hairline.
12

Tab bar

.tab-bar · .tab · .tab--scan
  • 5 items: Today · Diary · Scan · Recipes · Profile. Scan is a persimmon pill inside the bar.
  • Every indicator stays inside the bar: tabs are 44 pt tall with padding above and below, the pressed pill is inset 4 px, and the focus ring is inset.
  • Active = persimmon, bold label and filled icon, not colour alone. The 34 pt home-indicator area sits below.
13

Bottom sheet

.scrim · .sheet · .macro-tiles
  • For quick edits without leaving the screen, such as a portion or a meal choice.
  • Always has a handle and a close button. As a modal it traps focus, closes with Esc and returns focus to the control that opened it.
  • Macro tiles: three equal grid columns, the same padding, shared baselines and tabular numbers, all inside the sheet margins.
14

Toast

.toast · --success · --warning · --error
  • Confirms an action and offers Undo. It stays until the user dismisses it or does something else: no timer, and a ✕ to close.
  • One line, plus an optional action. Shown above the tab bar.
  • The red error toast is only for real failures, such as no connection.
15

Empty state

.empty · .empty--error
  • Say what's missing and give the next step: one primary action and one alternative.
  • Friendly, never blaming. Photo failures always offer manual search.
16

Badges and confidence

.badge · .confidence · .marker
  • Confidence = icon + word, on every detected food in a photo.
  • "Not sure" rows get a honey marker and a tint, and always offer alternatives.
  • Macro badges repeat the letter (P / F / C), so they're readable without colour.
17

Inline banner

.banner · .banner--offline
